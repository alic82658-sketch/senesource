Rappels normatifs clés du Système :
- Rayon 0 partout ; aucune ombre ; aucune icône décorative (seuls signes : → ← ▾ ✕ et le carré 7–8 px).
- Ocre `#A2621B` : trois usages seulement (n° de dossier, renvoi [n], chiffre-conséquence) + l'unique bouton primaire d'une page ; jamais en fond, jamais pour un verdict.
- Verdicts (5, fermés) : Exact · Exact, mais partiel · Trompeur · Faux · Invérifiable — Newsreader italique `--ink`, jamais colorés.
- Blanc pur `#FFFFFF` interdit sauf la page d'un document reproduit.
- Familles : Newsreader / Public Sans / IBM Plex Mono, graisses 400/500/600 uniquement.
- Un titre de dossier est toujours une question (≤ 140 caractères).
- Le statut d'une pièce est toujours écrit en toutes lettres (jamais porté par la seule forme du carré).
